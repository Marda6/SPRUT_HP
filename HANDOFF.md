## 2. Стек и запуск

Чистый HTML + CSS + JS, без сборки и зависимостей.

```
index.html              единственная страница — «Библиотека»
assets/css/tokens.css   токены: цвет, типографика, радиусы, размеры
assets/css/styles.css   компоненты и раскладка
assets/js/data.js       данные прототипа (проекты, компоненты, справочники)
assets/js/app.js        рендер и взаимодействия
assets/img/             SVG/PNG: экспорт из Figma + заглушки
.claude/launch.json     дев-сервер для превью (node .claude/serve.mjs, порт 8123)
.claude/serve.mjs       статик-сервер с Cache-Control: no-store
```

Открыть можно просто двойным кликом по `index.html`.

## 3. Структура страницы

1. **Титульная строка** — логотип, иконки проекта, вкладки открытых проектов, кнопки окна.
2. **Навигация разделов** — `Недавние · Библиотека · Локальные ┃ Расширения`, справа «Менеджер лицензий». Слева от разделителя места хранения, справа — отдельная библиотека компонентов. «Архив» убран.
3. **Тулбар** — заголовок «Библиотека» + переключатель разделов библиотеки `Проекты | Цифровое оборудование` (второй уровень навигации), справа «Загрузить проект», поиск, сортировка, «Фильры».
4. **Чипы** — свои для каждого раздела.
5. **Контент** — «Подборки» + «Проекты», либо «Компоненты».
6. **Правая панель** — своя для каждого раздела.

Собрана только «Библиотека». `Недавние`, `Локальные`, `Расширения`,
«Менеджер лицензий» — кнопки есть, страниц нет.

## 4. Раздел «Проекты»

- Карточки 4 в ряд, горизонтальные (превью 160px слева), высота 146px как в макете.
- **Название** — до двух строк с троеточием, место под две строки зарезервировано, полное имя в `title`.
- **Иконка напротив даты = тип проекта**, 4 состояния (`STATUS` в `data.js`):
  публичный (глобус) · мой в облаке (один человек) · мой, я поделился (две фигуры, большая тёмная) · доступен мне (две фигуры, большая полая).
  Файлы `icn-status-*.svg` нарисованы в `#F5F5F5` под тёмную тему, поэтому выводятся **CSS-маской** (`.status-icon--<ключ>` в styles.css): цвет берётся из токена, полупрозрачные части сохраняются. При появлении тёмной темы достаточно поменять токен.
- **Подпись в подвале = расположение** («Библиотека»). На «Недавних» там будут локальные пути.
- Ховер: синий бордер + синий заголовок. Selected: бордер + кольцо 1px + лёгкая тень.
- Звезда: у избранных видна всегда, у остальных по ховеру; клик переключает избранное.
- Чипы: `Все · Официальные · Избранные · Мои проекты · Доступные мне` (выводятся из типа проекта через `CHIP_BY_STATUS`).
- Панель проекта 360px: превью, шапка, кнопки, скроллится только середина (Информация/Оси/Тэги/Пользователи), низ закреплён.

## 5. Раздел «Цифровое оборудование» (DMC)

Название раздела по-русски — **«Цифровое оборудование»**, в англоязычной версии DMC.

**Карточка** горизонтальная, превью 120px слева, 4 в ряд (`--dmc-card-min: 430px`, `--dmc-card-w: 480px`):
название + звезда, свойства, разделитель, футер (плашка категории слева, цена справа).

**У каждой категории свой набор полей, цвет плашки и иконка превью** (`DMC_KINDS`):

| Категория | Поля | Цвет | Иконка |
|---|---|---|---|
| Схема станка | стойка, тип, оси, раб. зона, оснащение | зелёный | куб |
| Интерпретатор | стойка, **станок**, тип, оси | фиолетовый | терминал `>_` |
| Постпроцессор | стойка, **станок**, тип, оси | синий | `</>` |
| Комплект | всё, 6 строк | янтарный | слои |

- **Высота карточек одинаковая** независимо от набора полей: место под 6 строк (`DMC_MAX_FIELDS × 20px`), название в одну строку, плашки оснащения 20px без вертикальных отступов.
- **Оснащение в одну строку**, лишнее сворачивается в «+N» — функция `fitEquipment()`. На время замера ставится класс `is-measuring`, который отключает сжатие плашек, иначе строка всегда «влезает».
- **Цена**: `Бесплатно` / `Тех. поддержка` / сумма в рублях с разделением разрядов (`priceLabel`).
- Чипы одной строкой через разделитель: `Все · Мои компоненты · Избранные ┃ Все категории N · Схемы N · Интерпретаторы N · Постпроцессоры N · Комплекты N`. Счётчики считаются из данных.
- Кнопки «Загрузить …» в этом разделе нет.

**Панель компонента** (`#panel-dmc`, 420px), собрана по референсу страницы компонента:

- превью сверху (иконка категории);
- шапка: название + звезда, плашки «категория» и «тестирование», строка `компания ┃ N загрузок ┃ обновлён дата` через вертикальные разделители;
- **закреплено над вкладками**: кнопки «Получить пробную» / «Запросить постпроцессор» в один ряд, ссылка «Спросить о компоненте», цена в отдельной рамке (без цветового выделения);
- три вкладки: **Обзор** (описание, публикация) · **Параметры** (станок, стойка ЧПУ, тестирование) · **Связи** (подходящие постпроцессоры, интерпретаторы, автоподбор; по клику панель переключается на связанный компонент);
- **версию ENCY не показываем** — решение Руслана;
- заголовки групп без капслока: вес 600 + цвет, между группами разделительная линия;
- данные собираются из полей карточки в `dmcDetail()` / `dmcLinked()`, чтобы не держать два источника.

## 6. Осознанные отступления от макета

Все помечены комментариями в CSS рядом с правилом.

| Что | Как в Figma | Как в прототипе | Почему |
|---|---|---|---|
| Ряд навигации | 52px, табы 40px | 44 / 36, gap 4 | просил компактнее, иерархия сохранена (36/14px против 32/12px у переключателя) |
| Активная вкладка проекта | padding 11px | 16px, как у остальных | левый отступ был неодинаковым |
| Контролы тулбара | 40px | `--control-h: 32px` | рядом с переключателем 40px смотрелись тяжело |
| Рамка карточки | только тень `0 0 1px` | `--card-border: rgba(9,30,51,.16)` | на тусклых мониторах карточки сливались с белым |
| Переключатель вида (список/плитка) | есть | удалён | вид только один |
| Иконка «Фильры» | плюс обводкой `#F3F2F3` | убрана | невидима на светлом фоне, давала фантомный отступ 18px |
| «Рабочая зона, мм» | полностью | «Раб. зона, мм», полный текст в тултипе | 24px, которых не хватало, чтобы влезла ещё карточка в ряд |
| Скроллбары | системные | 8px, бегунок `rgba(9,30,51,.2)`, `scrollbar-gutter: stable` | иначе при фильтрации раскладка прыгала по горизонтали |

## 8. Грабли, на которые уже наступали

1. **Специфичность CSS.** Несколько раз правило из панели перебивало правило карточки при равной специфичности, потому что идёт ниже в файле: `.tag` vs `.tag--neutral` (нужно `.tag.tag--neutral`), `.panel` vs `.panel--dmc` (`.panel.panel--dmc`), `.select img` vs `.chev img`, `.access img:nth-child(N)` ловил одиночные глифы. При странном поведении сначала смотреть порядок и специфичность.
2. **`url()` в кастомном свойстве** резолвится относительно CSS-файла, где объявлено. Из-за этого путь маски превращался в `assets/css/assets/img/...`. Глифы масок привязаны классами прямо в `styles.css`.
3. **`repeat(auto-fill, minmax(min, max))`** — число колонок считается по **максимуму**. Чтобы влезло больше карточек, считаем по минимуму (`minmax(min, 1fr)`) и ограничиваем `max-width` самой карточки.
4. **Кеш браузера.** Пока не добавили `Cache-Control: no-store` в дев-сервер, страница отдавала старые css/js — были ложные ошибки в консоли и «не применившиеся» правки. Если что-то не изменилось — Ctrl+F5.
5. **Масштаб.** У Руслана масштаб дисплея Windows 150% (`devicePixelRatio = 1.5`), поэтому скриншоты приходят уменьшенными. Сама страница в 100% (`visualViewport.scale = 1`), зума в коде нет.
6. **Проверять замерами.** Быстрее и надёжнее скриншотов: `getComputedStyle` + `getBoundingClientRect` через `javascript_tool`. Осторожно: если в одном вызове сначала взять элемент, потом кликнуть (перерисовка), ссылки станут «мертвыми» и вернут нули.
